## Adding an executed record

Use the next stable evidence ID (for example `EVD-001`) and complete every field; use **Not applicable** rather than leaving ambiguity. Describe the method generically in public, record source and deployed SHAs separately, and put no secret location or raw private content in the ledger. “Private evidence retained” is only **yes**, **no**, or **not applicable**. A sanitized summary should state pass/fail/partial outcome, measured values where relevant, scope, and known limitations.
